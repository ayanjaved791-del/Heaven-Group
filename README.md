# Heaven Builders & Developers

Marketing website for Heaven Group — *Building Today, A Better Tomorrow™*.

Vite + React + Tailwind CSS. Edit all company details (phone, WhatsApp, email, address,
projects, figures, testimonials) in `src/data/heaven-group.ts`.

```bash
npm install
npm run dev
```

Deploy: import this repository on [vercel.com/new](https://vercel.com/new) — settings are
detected automatically (`vercel.json`).
